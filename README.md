This is a simple front-end clone of the Blinkit website built using only HTML and CSS. The project focuses on replicating the layout and design of the original platform without using JavaScript or any frameworks.

Features:
1)Responsive homepage layout
2)Navigation bar similar to Blinkit
3)Product sections and categories
4)Clean UI using pure CSS
5)Static design (no backend or interactivity)

Technologies Used:
HTML5 
CSS3

This project was created for learning and practicing front-end development skills, especially:
1)Layout design
2)Flexbox / Grid
3)Styling and positioning
